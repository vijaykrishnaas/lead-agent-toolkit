**Bug found and fixed in the same run:** running `claude plugin validate ./plugin --strict` (the CLI is available in this environment) surfaced a real, pre-existing error: both skills' `argument-hint` frontmatter field — `argument-hint: [owner] [gh-repo] [pr-number] [base..head]` (review-pr) and `argument-hint: [owner] [gh-repo] [since]` (standup) — is invalid YAML. A value starting with `[` opens a YAML flow sequence, and the trailing space-separated `[...]` groups after the first one's closing `]` are leftover tokens the parser can't attach anywhere, so the whole frontmatter block fails to parse; per `claude plugin validate`'s own message, "At runtime this skill loads with empty metadata (all frontmatter fields silently dropped)." This bug was already present in the two pre-existing `.claude/skills/*/SKILL.md` files from tasks 9 and 10 — it wasn't introduced by this task, just newly exposed by being the first time anything in this repo actually ran `claude plugin validate` against them.
